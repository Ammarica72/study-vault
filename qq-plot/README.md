# Q-Q Plot Generator

A Python program for generating **Quantile-Quantile (Q-Q) plots** to assess whether a dataset follows a normal distribution.

The script can generate sample datasets or use a predefined reference dataset, compute the theoretical normal quantiles, display 
a Q-Q plot with a fitted reference line, and export the underlying Q-Q calculations to an Excel spreadsheet. 
The code is designed to be easy to understand and extend, making it suitable for learning, teaching, and statistical data analysis.
